Before you write

  1. Check the documentation and its questions.
  2. Make sure you are on the latest version (see the changelog). The version is in Theme settings > Theme information.
  3. Turn off apps one by one if the problem started after installing an app.
  4. Have your store address, a link to the page and a screenshot ready.
